# Temporary Files & Scripts

This directory is an archive for one-off Python scripts, testing files, and temporary data dumps used during the development of ReefGPT.

## Contents:
- **Database Scripts**: Temporary scripts used to seed, test, or clean up the Supabase database (`test_db.py`, `dedupe.py`, etc.).
- **Hardware Data Dumps**: Raw XML and JSON outputs from the Neptune Apex controller (`apex_datalog.xml`, `apex_status.json`) used for offline testing and reverse-engineering the data structures.
- **Debugging**: Scripts used to isolate and test specific backend logic (`debug_sync.py`, `test_livestock.py`).

Files in this directory are typically unused by the main application and are kept only for historical reference or debugging.
