# ReefGPT Documentation

This directory contains the core documentation and planning files for the ReefGPT project.

## Files:
- **`project_vision.md`**: The high-level master plan. Details the "why" and "what" of ReefGPT, including the target audience, the core agentic AI philosophy, and the multi-tenant SaaS architecture.
- **`current_functionality.md`**: The technical state of the app. Documents how the backend and frontend currently interact, step-by-step user flows, hardware integrations, and how to run the application.
- **`future_plans.md`**: The actionable roadmap. A concise list of outstanding tasks and detailed implementation plans for upgrading the AI, testing frameworks, and new features.
